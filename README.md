# YC 2026 Vertical AI Website References

A searchable gallery of 197 high-quality website examples from Y Combinator's 2026 batches, with source links and local screenshots.

## Browse the gallery

Visit the [live website](https://ktwu01.github.io/yc_vertical_ai_sites/).

Use the batch buttons to filter the gallery, or search by company, industry, or slogan.

## Data files

- `vertical_ai_2026_index.csv` and `vertical_ai_2026_index.json`: 277 vertical AI companies
- `yc_2026_all_624_audit.csv` and `yc_2026_full_audit.json`: complete 2026 cohort audit
- `homepage_quality_ratings.json`: homepage quality ratings
- `vertical_ai_2026_report.md`: written findings
